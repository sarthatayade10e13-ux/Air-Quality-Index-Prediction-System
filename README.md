# Air-Quality-Index-Prediction-System

Overview

Air pollution varies significantly across different locations, making large Air Quality Index (AQI) datasets difficult to analyze manually. This project focuses on analyzing air quality data across Indian locations to study relationships between pollutants and AQI, and uses Machine Learning to predict and identify pollution levels. 


Project Objectives

Analyze major air pollutants and AQI patterns. 
Study relationships between different pollutants and the AQI.   
Predict AQI and identify varying pollution levels using Machine Learning. 

Machine Learning Algorithms

Random Forest Regression: Uses six pollutant parameters as inputs to automatically predict the AQI.  
R² Score: 0.922   
MAE: 7.76  
K-Means Clustering: Groups locations into low, moderate, and high pollution clusters.
